# Security

Please do not open a public issue for a suspected vulnerability.

Use the repository’s private GitHub Security Advisory flow to report the issue. Include the affected version or commit, reproduction steps, impact, and any suggested mitigation. Do not include real CRM credentials or customer data.

The project will acknowledge a complete report as soon as practical and coordinate remediation and disclosure with the reporter.

Only the latest commit on `main` is supported during the initial development phase.
